================================================================================
  WHAT HAPPENS AUTOMATICALLY
================================================================================

When you run .\run.ps1 -Mode pipeline:

1. System loads config/pipeline.yaml
2. Checks if Ollama is running
   → If not: Auto-launches
3. Checks if model is available
   → If not: Auto-pulls (wait ~5 min first run)
4. Checks if MT5 is running
   → If not: Auto-launches
5. Connects to MT5 with your credentials
6. Runs analysis pipeline (hourly)
7. Logs all decisions to JSON files
8. Tracks statistics in memory

User does NOTHING after clicking "Run"
